 # KPD

This repository contains a collection of Python NLP assignments and exercises that I have completed as part of a course. Each assignment focuses on different aspects of natural language processing, including text preprocessing, tokenization, and more.

## Purpose

- Practise Python programming through practical assignments.
- Learn and apply fundamental NLP concepts.
- Work with text processing, data preparation, and language analysis.
- Build a foundation for developing more advanced NLP projects.

The repository is intended for educational use and documents my progress while learning and improving my Python NLP skills.
